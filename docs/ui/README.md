# Kanopi UI

Catatan desain untuk platform ledger pasok EarthLine. Sumber kebenaran token ada di [`src/styles.css`](../../src/styles.css) (`@theme`). Ubah token dulu, baru komponen.

| File | Isi |
| --- | --- |
| [warna.md](./warna.md) | Palet, alasan teal, pemakaian semantik |
| [tipografi.md](./tipografi.md) | IBM Plex Sans + Plex Mono |
| [komponen.md](./komponen.md) | Login, mark, ledger, peta, chip |

**Bukan** salinan Kanopi 0.0.12 (sidebar navy, Space Grotesk, aksen biru). Arah visual: kertas hangat, aksen teal, tipografi teknis.

Bahasa antarmuka default **English**, Indonesia sebagai opsi kedua (`kanopi.lang`).
